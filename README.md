# Gullni hringurinn — Verkefni 7

Responsive vefsíða um sex staði á Gullna hringnum og í nágrenni hans: Gljúfrastein, Þingvelli, Gullfoss, Geysi, Skálholt og Kerið.

## Skoða vefinn

Opnaðu `index.html` í vafra. Vefurinn er gerður úr HTML og CSS og þarf ekki að setja upp pakka. Nettenging þarf fyrir Google Maps, leturgerðir og myndir frá Wikimedia Commons.

## Skrár

- `index.html` — forsíða, staðakort, Google Maps og samantekt.
- `gljufrasteinn.html`, `thingvellir.html`, `gullfoss.html`, `geysir.html`, `skalholt.html`, `kerid.html` — undirsíður um staðina sex.
- `heimildir.html` — heimildir fyrir staðatexta og myndir.
- `styles.css` — sameiginlegt útlit og skjástærðir.
- `images/gljufrasteinn.svg` — upprunaleg SVG-teikning fyrir verkefnið.

## Birta á GitHub Pages

1. Búðu til GitHub repository sem heitir `verkefni-7`.
2. Settu allar skrár og `images`-möppuna í rót repository-inu.
3. Opnaðu **Settings → Pages**.
4. Veldu **Deploy from a branch**, branch `main` og möppuna `/(root)`, vistaðu svo.
5. Þegar birting hefur lokið verður forsíðan á `https://NOTANDI.github.io/verkefni-7/index.html`. Skiptu `NOTANDI` út fyrir GitHub-notendanafnið þitt.

## Verkefniskröfur sem eru útfærðar

- Sex sjálfstæðar undirsíður með frekari upplýsingum um staðina.
- Forsíða með sex upplýsingakortum, myndum og tenglum á undirsíður.
- Myndir á forsíðu hverfa á farsímaskjá; undirsíðurnar halda myndum.
- Merkingarlegt HTML5 með `header`, `nav`, `main`, `section`, `article`, `aside` og `footer`.
- Sveigjanlegt útlit fyrir síma, spjaldtölvur og stærri skjái.
- Google Maps iframe sem bendir á Gullfoss.
- Mynda- og textaheimildir eru skráðar á `heimildir.html`.
